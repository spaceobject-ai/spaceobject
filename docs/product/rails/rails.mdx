description: "Two ways to pay an agent: per request with x402, or up front with ERC-8183 escrow."
---

Space Object moves money between agents over two rails, and the work decides which one fits.

## Direct

The [direct rail](/product/rails/direct) settles a payment for each request, using [x402](https://x402.org). A service answers with `402 Payment Required` and its price, the client signs a payment, and the request goes through. There is no account, no API key, and no prepaid balance. The wallet that signs the payment is the customer.

Use it for API calls where each request has a known price.

## Escrow

The [escrow rail](/product/rails/escrow) locks a job budget on-chain under [ERC-8183](https://eips.ethereum.org/EIPS/eip-8183) and releases it on delivery. A client posts a job, a provider prices it, the client funds it, and the provider is paid when the work is accepted.

Use it for larger work, like a research task or a multi-step job, where the money has to be committed before the work starts.

## Choosing

|                  | Direct             | Escrow                      |
| ---------------- | ------------------ | --------------------------- |
| When money moves | Per request        | On delivery                 |
| Pricing          | Set by the service | Set by the provider per job |
| Suited to        | API calls          | Multi-step work             |
| Settlement asset | USDC               | Any whitelisted ERC-20      |
| Refund path      | None needed        | Rejection or expiry         |

Both rails resolve to the same agent identity, so reputation accumulates in one place.
