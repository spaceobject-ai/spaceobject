Tools are paid data services: scraping, enrichment, search. An agent describes what it needs in plain language, gets a ranked list with each price, and calls the one it wants. The call settles over the [direct rail](/product/rails/direct), so payment is a signed x402 authorization from the caller's wallet. No account, no API key, no prepaid balance.

The catalog holds 2,100+ per-call tools across 75+ providers: social data, SERP and scraping, B2B and people enrichment, finance and crypto, real estate and autos, jobs and salaries, weather, news, and more.

## What the domain carries

A tool is defined by what a caller needs, not by who lists it:

- An id, the handle `sun tool call` takes
- A description, and a relevance score for the query
- The price of one call, in USD
- A structured input sketch, one JSON Schema per parameter location (path, query, body), or null when the tool takes no declared input

Callers (the API, the CLI, agents) see only this shape. Provider-specific fields never reach them.

## What is listed

Only per-call tools appear in the catalog. A per-call price settles once, up front, with the result in the same request, which is the only billing x402 can prepay. Metered endpoints and endpoints without published pricing are left out.

Every call is billed at a $0.01 minimum, and the catalog shows prices at that floor, so the listed price is what a call actually costs.

## The discovery integration

Space Object defines the tool domain and the interfaces around it. The catalog itself comes from [Monid](https://monid.ai), our discovery integration. Monid's catalog is mapped onto the shared tool schemas at the edge, so a provider without a mapping cannot appear, and a second provider can be added later without callers noticing a difference.

Search runs through the Space Object API, which holds the integration key. Calls do not pass through it: the caller's wallet pays the provider's x402 gateway directly.

## Using tools

```sh
sun tool discover "linkedin profile by url"
sun tool call apify/apidojo/tweet-scraper -i '{"searchTerms":["AI"],"maxItems":10}'
```

The [CLI reference](/tools/cli#tool) lists the flags. The error codes are `TOOL_ID_INVALID`, `TOOL_PAYMENT_FAILED` and `TOOL_NETWORK_UNSUPPORTED`.
